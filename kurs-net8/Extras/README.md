# Materiały dodatkowe

Katalog zawiera wzorce niewymagane w rdzeniu kursu oraz starsze warianty
przykładów. Uruchamiaj je przez `MaterialyDodatkowe.sln`. Przed użyciem na
zajęciach sprawdź README i aktualność przykładu.

Solucja obejmuje 51 wybranych projektów przeniesionych do `net8.0`. Najstarsze
projekty historyczne, które nie mają formatu SDK-style albo nie definiują
docelowej platformy, pozostają jako archiwum poza solucją.
